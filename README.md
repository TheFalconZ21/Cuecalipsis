# Cuecalipsis

Base de organización para un proyecto 3D de acción/ritmo. El repositorio contiene por ahora documentos de contexto y estructura de carpetas; todavía no tiene motor seleccionado, código ejecutable, configuración de balance ni contratos implementados.

## Trabajo por roles

- Dev 1: `src/modules/rhythm-player/` y `assets/audio/`
- Dev 2: `src/modules/scale-world/`
- Dev 3: `src/modules/combat-hordes/`
- Dev 4: `src/modules/art-vfx-ui/`, `assets/models/`, `assets/shaders/`, `assets/ui/`
- Contratos compartidos: `src/core/` (coordinar cambios entre los cuatro roles)

Revisar el [protocolo de agentes](AGENTS.md) y los `DECISIONS.md` del módulo correspondiente antes de implementar. Los seis PDF de la raíz son el material de referencia.
