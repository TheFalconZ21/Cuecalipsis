# Huasomodelo — Dev 4

Modelo del huaso riggeado para el prototipo, exportado en GLB y con escena editable Blender.

- `huasomodelo.glb`: asset que se debe integrar en el proyecto.
- `huasomodelo.blend`: fuente editable.
- `huasomodelo-preview.png`: vista previa en color.

Incluye el rig `CuecaHumanoid_Rig` y el logo CODEX en el sombrero. El archivo fuente original de Meshy se mantiene separado en `assets/models/huaso/`.
